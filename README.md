# Skin Ears (Minecraft 26.3)

A Fabric client-side mod project that adds cat or dog ears to the player model. The ears are tinted from the top of the player's skin by default. Press **K** in game to choose cat/dog, change the color with RGB sliders, or reset to the default skin-matching style.

## Building

This repository includes a GitHub Actions workflow that runs `gradle build` with JDK 25. Open the **Actions** tab, select **Build Skin Ears mod JAR**, and download the artifact after a successful build.

The compiled mod JAR belongs in your Minecraft 26.3 Fabric `mods` folder alongside Fabric API.

> Build and compatibility are being verified; a workflow failure means the mod is not yet ready to install.
